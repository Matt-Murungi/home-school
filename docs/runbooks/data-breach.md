# Data breach runbook (pointer)

The personal data breach procedure (DP-8, issue #142) lives in `docs/legal/breach-procedure.md` so that it sits with the other legal documents and the processor register. Open that file; this page exists because the ticket names `docs/runbooks/data-breach.md`.

Quick start if you are reading this during an incident:

1. Write down the time you became aware (this starts the clock).
2. Tell the incident lead (owner by default) now.
3. Contain first (revoke the key, sign out sessions, close the bucket), preserve evidence second, then follow the clock in `docs/legal/breach-procedure.md`.
